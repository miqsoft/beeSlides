<kbd>⌘</kbd> on macOS is <kbd>Ctrl</kbd> on Windows and Linux.

## Editor

| Keys | Does |
|---|---|
| <kbd>⌘</kbd>+<kbd>S</kbd> | Save |
| <kbd>⌘</kbd>+<kbd>Z</kbd> / <kbd>⌘</kbd>+<kbd>⇧</kbd>+<kbd>Z</kbd> | Undo / redo |
| <kbd>⌘</kbd>+<kbd>D</kbd> | Duplicate the slide or selection |
| <kbd>Enter</kbd> (slide list) | New slide (<kbd>Ctrl</kbd>+<kbd>M</kbd> on Windows/Linux) |
| arrows / <kbd>⇧</kbd>+arrows | Nudge the selection 1 px / 10 px |
| <kbd>G</kbd> / <kbd>⇧</kbd>+<kbd>G</kbd> | Group / ungroup |
| <kbd>⌘</kbd>+<kbd>G</kbd> | Show or hide the grid |
| <kbd>C</kbd> | Add a comment |
| <kbd>⌘</kbd>+<kbd>,</kbd> | Settings |
| <kbd>⌘</kbd>+<kbd>+</kbd> / <kbd>−</kbd> / <kbd>0</kbd> | Zoom the whole interface |
| <kbd>F5</kbd> (desktop) | Present |

## Presenting

| Key | Does |
|---|---|
| <kbd>→</kbd> <kbd>Space</kbd> / <kbd>←</kbd> | Next / previous |
| number, then <kbd>Enter</kbd> | Jump to that slide |
| <kbd>F</kbd> | Toggle fullscreen |
| <kbd>S</kbd> | Speaker view |
| <kbd>L</kbd> | Laser pointer |
| <kbd>P</kbd> / <kbd>H</kbd> / <kbd>E</kbd> | Pen / highlighter / eraser |
| <kbd>C</kbd> | Clear the ink |
| <kbd>M</kbd> | Reduce motion |
| <kbd>K</kbd> | Kiosk (self-running) |
| <kbd>Esc</kbd> | End the show |
