Your deck is a plain, readable JSON block inside the file, so an assistant
that can read and write text can edit your slides. No plugin, no API.

<Tabs syncKey="app">
  <TabItem label="Desktop app">
    The desktop app has Claude built in.

    - **Claude Code terminal** (<kbd>⌘</kbd>/<kbd>Ctrl</kbd>+<kbd>`</kbd>, or
      the terminal button in the title bar): say what you want in plain words,
      and Claude edits the open deck while you watch.
    - **Send to Claude**: leave [comments](../../share/comments/) on your
      slides, then hand all open ones to Claude at once (Home tab, or
      **Play ▸ Send to Claude**).
    - **AI chat**: **Settings ▸ AI chat** connects a chat panel to the
      provider you choose.
  </TabItem>
  <TabItem label="Browser">
    The browser editor has no AI built in. Round-trip the deck through any
    chatbot instead, [as below](#in-the-browser-any-chatbot).
  </TabItem>
</Tabs>

## In the browser: any chatbot

1. **Save ▾ ▸ Copy document JSON**. Use **…without pictures** to keep it short.
2. Paste it into the chat and ask for the change.
3. **Save ▾ ▸ Replace from JSON…** and paste the answer back. This can be undone.

This works in the desktop app too (**File ▸ Export to…** and **File ▸ Import**).

<Aside type="tip" title="Claude Code in your own terminal">
  Install the BeeSlides plugin and Claude Code works on the decks open in the
  desktop app, with the same tools and skills as the built-in panel: see
  [Claude Code and other AI apps](../outside-apps/).
</Aside>

<Aside title="Other coding agents and local models">
  Aider, a local model or any agent without MCP can edit the
  `.beeslides.html` file directly with the [agent guide](https://github.com/miqsoft/beeslides/blob/main/docs/agents.md).
  That edits the file blind: nothing renders or measures the slides, so it
  suits text changes better than building a deck. With a local model nothing
  leaves your machine.
</Aside>
