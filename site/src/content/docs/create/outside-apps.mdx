The desktop app has Claude built in. You can also work on your decks from
the AI app you already use. Claude Code in your own terminal gets everything
the built-in panel has: the deck tools and the skills that build, restyle and
polish decks.

The AI app works on your decks through BeeSlides: screenshots, measuring
and layout happen in the app. With BeeSlides open, you see every change as it
happens. Without it, Claude Code uses a hidden BeeSlides that saves every
change to the deck file (see [Without the BeeSlides window](#without-the-beeslides-window)).

## Claude Code

<Steps>

1. In BeeSlides, open **Settings ▸ AI chat ▸ Advanced** and turn on
   **Allow AI apps outside BeeSlides**. (Skip this to work without the
   BeeSlides window.)

2. In Claude Code, install the BeeSlides plugin:

   ```
   /plugin marketplace add miqsoft/beeslides
   /plugin install beeslides@beeslides
   ```

3. Open the deck you want to work on in BeeSlides, or just name its file.

4. Ask Claude Code, for example *"Build a 12-minute conference talk from
   paper.pdf into the open deck"* or *"… into talk.beeslides.html"*. The
   first time, BeeSlides asks whether to allow Claude Code. Choose
   **Allow**.

</Steps>

The plugin needs [Node.js](https://nodejs.org) 18 or newer on your PATH,
and BeeSlides installed and opened once since it was installed or updated
(that is how the plugin finds it).

### Without the BeeSlides window

When BeeSlides is not open (or **Allow AI apps outside BeeSlides** is off),
Claude Code starts a hidden BeeSlides of its own for the chat. Nothing
appears on screen and nothing shows in the Dock. Claude opens the deck file
you name (or makes a new one), and every change is saved to that file as it
happens. When the chat ends, the hidden BeeSlides saves and quits. This also
works over SSH and in scripts.

It uses your language and icon library settings, but leaves your Recent
list alone. An icon server that needs an access key does not work there.

### The BeeSlides pane

The plugin adds a **BeeSlides** pane beside the chat. It opens by itself as
soon as Claude starts on a deck when the terminal is wide enough (about 144
columns; 110 once you have opened it yourself). In a narrower terminal the
status line says so: type `/beeslides` to open it at any width.

- It shows the deck, the latest slide, and a list of what Claude has done
  so far. Without the BeeSlides window, each slide appears there as soon as
  it is written.
- When Claude offers designs for a slide, the pane shows each one with a
  **Use 1**, **Use 2**, … button and **Keep current**. Press one, or just
  answer with the number. Claude learns your pick either way.
- **‹ prev** and **next ›** (keys `p` and `n`) swap through the deck,
  **jump** (`j`) lists every slide with its open comments, and **live**
  (`l`) follows Claude again. The slide's speaker notes show under it.
- Under the slide, type a comment and press Enter. It is saved on that slide
  as a comment for Claude, and Claude reads it right away, even in the middle
  of building the deck. **on: slide** (`e`) lets you pick one element of the
  slide to comment on instead. **more visual** (`v`) and **less text** (`t`)
  are ready-made comments; **designs** (`d`) asks for other designs for the
  slide.
- When Claude has fixed a comment, the pane shows its reply with **Accept**
  (`a`) and **Reopen** (`r`): Reopen asks what is still wrong and sends that
  back. **before** (`b`) shows the slide as it was when you wrote the
  comment. The comments are in the file, so you find them in the app too.
- **hold** (`h`) asks Claude to stop after the step it is on, so you can look
  before it builds more; **go on** lets it carry on.
- **open** (`o`) opens a copy of the deck, as last saved, in your browser.

Pictures appear in terminals that can show images (kitty, Ghostty, iTerm2
3.5 or newer); elsewhere the pane lists what there is. With BeeSlides open,
you can also pick in the app as before.

### What to ask for

| You say | What happens |
|---|---|
| "Build a talk from paper.pdf" | Claude asks a few questions about the talk (purpose, length, how full a slide may be). It shows an outline and 2–3 looks to pick from in BeeSlides, writes one slide of each kind for you to check, then builds the rest. |
| "Give this deck a glow-up" | It keeps every word and number and gives the deck a new look. You pick the look first. |
| "Clean up the deck" | It fixes alignment, spacing and readability, and keeps the look. |
| "Show me other designs for this slide" | 2–3 designs appear side by side in BeeSlides and in the BeeSlides pane; click **Use** on the one you want. |
| "Make the title on slide 3 shorter" | Just that, with no questions. |

Claude Code asks its questions as choices to pick from, with its
suggestion first. Say *"no questions"* or *"just do it"* if you don't want
any: Claude then asks nothing, states its assumptions, and builds.

## Claude Desktop, Cursor and other MCP apps

Any app that speaks MCP can use the deck tools. They don't get the skills,
which are Claude Code only. Add a server to the app's MCP settings that runs
the plugin's launcher, or BeeSlides' own server file:

```json
{
  "mcpServers": {
    "beeslides": {
      "command": "node",
      "args": ["<BeeSlides folder>/agent/beeslides-mcp.mjs", "--endpoint", "<BeeSlides folder>/agent"]
    }
  }
}
```

The BeeSlides folder is `~/Library/Application Support/BeeSlides` on macOS,
`%APPDATA%\BeeSlides` on Windows and `~/.config/BeeSlides` on Linux.
BeeSlides writes `agent/beeslides-mcp.mjs` there when you turn the setting
on.

## Allowing and taking back

- Each app asks once, the first time it connects, and BeeSlides remembers
  your answer. **Settings ▸ AI chat ▸ Advanced ▸ Forget allowed apps** makes
  every app ask again.
- Turning **Allow AI apps outside BeeSlides** off disconnects every app at
  once. Turning it on again later gives a new access key, so an app that was
  connected before has to connect again.

<Aside title="What it can and cannot reach">
  An allowed app can read and change the decks open in BeeSlides, the same
  way the built-in Claude panel can. It talks to BeeSlides over a local
  connection only this user account can open; there is no network port.
  Any program running under your account could try to connect, which is why
  BeeSlides asks before it lets an app in. Allow only apps you started
  yourself.
</Aside>

## When it doesn't work

| Claude Code says | Do this |
|---|---|
| BeeSlides is not set up for AI apps outside it | Turn on **Allow AI apps outside BeeSlides** (step 1), then run `/mcp` in Claude Code and reconnect **beeslides**. |
| BeeSlides did not allow this app to connect | You chose **Don't Allow**. Ask again and choose **Allow**. |
| BeeSlides is not running | Open BeeSlides yourself, then try again (or start a new chat to work without the window). |
| No deck is open in BeeSlides | Open the deck, or tell Claude which file to work on. |
| BeeSlides is not installed on this computer, or it has not been opened since | Install or update BeeSlides and open it once, then run `/mcp` and reconnect **beeslides**. |
| BeeSlides could not be started in the background | Open BeeSlides once (so the plugin finds it), then start a new chat. |
