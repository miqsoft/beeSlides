## Why a file?

<CardGrid>
  <Card title="One file, forever" icon="document">
    Deck, fonts, images, charts, animations and the editor travel together.
    A copy from 2026 will open in 2036.
  </Card>
  <Card title="It saves itself" icon="pencil">
    Press ⌘S and the file rewrites its own data block. No app to install,
    no account, no cloud.
  </Card>
  <Card title="View-source honest" icon="open-book">
    Your deck is plain JSON near the top of the file. No binary format,
    no lock-in — and any AI that can edit a file can edit your slides.
  </Card>
  <Card title="Local-first, provably" icon="approve-check">
    No server, ever. Offline mode switches every network feature off, and a
    test fails the build if code reaches the network another way.
  </Card>
</CardGrid>
