Each example is a single `.beeslides.html` file in present-only form: it opens
in your browser, you press **Start**, and it presents. Nothing is fetched; a
downloaded copy works offline. To edit one, open it in the
[desktop app](../install/), whose start page also offers the bee deck as
**Example deck**. The bee deck can also be
[edited in your browser](../../app/how-bees-fly.beeslides.html).
