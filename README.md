## Install

```bash
git clone https://github.com/miqsoft/beeSlides.git
cd beeSlides
npm run setup          # macOS, Windows, Linux · needs Node.js 22.12+
```

This builds and installs the desktop app, with Claude built in. No install
needed to view, edit or present a deck: every file carries its own editor and
opens in any browser. See [Install](https://miqsoft.github.io/beeSlides/start/install/).
